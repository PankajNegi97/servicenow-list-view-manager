📖 Quick Start Guide

  1. 1
    Create or Capture Profile

    Click 📸 Capture from Page while on a ServiceNow list or List Layout page, or type column names manually (one per line).

  2. 2
    Open List Layout in ServiceNow

    In ServiceNow, right-click any table header → Configure → List Layout (keep this screen open!).

  3. 3
    Click "Apply" & Wait

    Click Apply on your saved profile and wait a few seconds while columns are automatically moved and saved!

  4. 4
    Backup & Share

    Use Export and Import buttons to backup or share column presets JSON with teammates.
